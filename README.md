# 五行島的種子守護者

給國小孩子邊玩邊複習的島嶼探險遊戲（第一版：國語、南一版）。

- 網址：https://pennychenyi.github.io/taki-island/
- 手機、iPad 都可以玩；在 Safari 按「分享 → 加入主畫面」，就能像 App 一樣全螢幕開啟。

## 第一階段內容
- 家長用 Google 登入，再建立孩子檔案；也可以用試玩模式（只存在這台裝置）
- 選擇主角造型
- 開場故事《五行島的種子守護者》（6 段，可語音播放）
- 3D 世界地圖：可旋轉、縮放；晚上 8 點到早上 6 點自動切換成夜晚模式
- 台灣島・五行試煉：寫「金木水火土」的筆順，答題，開三選一寶箱，孵化 Rara
- 交通系統：每次登入第一趟免費；騎靈獸要先孵化
- 化輸為贏・修煉場（目前可以看錯字怪清單）
- 家長專區：練習時間、正確率、最常錯的字

## 資料來源
- 筆順：中華民國教育部《國字標準字體筆順學習網》，經 g0v [zh-stroke-data](https://github.com/g0v/zh-stroke-data) 整理
- 注音、筆畫：教育部國語辭典

## 檔案說明
| 路徑 | 內容 |
|---|---|
| `js/main.js` | 畫面流程 |
| `js/store.js` | 登入與雲端存檔（Firebase） |
| `js/writer.js` | 筆順寫字格 |
| `js/map3d.js` | 3D 地圖 |
| `js/story.js` | 開場故事文字 |
| `js/data/strokes/` | 筆順資料，檔名是字的 Unicode 碼 |
| `firestore.rules` | 資料庫權限規則（貼到 Firebase 主控台） |

測試小技巧：網址後面加 `?day` 或 `?night`，可以強制切換白天或夜晚。
